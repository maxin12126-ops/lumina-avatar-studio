DATA & PRIVACY

Privacy notice

Effective date: October 15, 2026

This notice describes the current single-user local prototype and its public information website. Pinterest API access is pending. The website does not provide public Pinterest account connection, account registration, payments, or file uploads.

1. Who operates this project

lumina Avatar Trend Studio is operated by the owner of the GitHub account maxin12126-ops (the app owner). The application supports the owner's original cartoon avatar workflow. Privacy and support enquiries can be raised through the project's issue tracker. Issues are public; include only the topic of your request, without credentials, private account data, or customer files.

2. Information on this website

This static website has no account system, forms, advertising scripts, analytics scripts, or application cookies added by the project. Website files are hosted on GitHub Pages. GitHub states that it logs and stores visitors' IP addresses for security purposes. Its processing is described in the GitHub Privacy Statement.

3. Information used by the local application

  • Keyword trend research: once access is granted, regional keywords, relative-interest time series, growth rates, source dates, request parameters, HTTP status, and rate-limit information returned by Pinterest.
  • Owner-entered visual reviews: public Pin URLs, visible creator identifiers or titles, visual tags, avatar suitability scores, review decisions, and screenshots selected by the owner. The tool does not automatically download Pin image files.
  • Local market evaluation: note URLs, owner-entered baseline and test metrics, and selected screenshots used to evaluate the owner's publishing results.
  • Original artwork workflow: images imported by the owner, work identifiers, creation briefs, review status, original artwork, and publishing previews.
  • Authentication: a Pinterest access token supplied locally through an environment variable for authorized API calls. The current application does not save that token in its trend database or reports.

4. Purposes and AI-assisted creation

These records help the owner assess trend evidence, avoid repeated ideas, review avatar suitability, and plan original artwork, including artwork offered for sale. AI-assisted artwork generation is a separate creation step. The current trend tool does not automatically send its raw Pinterest API responses, access tokens, screenshots, or review database to an image-generation service. The owner may use general creative characteristics in a manually reviewed brief.

The project does not use Pinterest data to train or fine-tune models, and does not sell or redistribute Pinterest datasets or Pin images. It does not automatically post content to Pinterest or other platforms.

5. Storage and sharing

The application's source snapshots, review screenshots, database, briefs, and exported artwork are stored on the owner's Windows computer. These records are not uploaded to this public website or its public source repository. Authorized API requests send the access token and request parameters to Pinterest. Pinterest's own services are subject to the Pinterest Privacy Policy. GitHub processes website visits and any public issues under its own policies.

6. Retention, deletion, and access removal

Local records remain until the owner deletes them; the current prototype has no automatic retention or purge schedule. The owner can remove local snapshots, screenshots, database records, and artwork exports. To stop API access, the owner can remove the configured token and revoke the application's authorization through Pinterest. Removing a token alone does not delete previously stored local records.

If you believe a review record identifies you and you would like to raise a question or deletion request, use the contact route in section 1. Mention only the general topic in a public issue so the owner can coordinate any necessary follow-up. Do not post personal evidence publicly.

7. Changes to this notice

The notice will be updated if the application's data use changes, including before introducing public user accounts or a hosted data-processing service. The effective date above identifies the current version.
